# Documentation Index

This folder contains the living documentation for the Untab Pomodoro extension. Use the quick links below to jump to the material we actively maintain. Files that describe historic fixes or exploratory work are parked in `docs/archive/` for reference but are no longer part of the day-to-day workflow.

## Active References

- `MODULE_REFERENCE_GUIDE.md`: maps the former monolithic `popup.js` and `notification-manager.js` logic to the current module layout (`popup/` subfolders and notification helpers).
- `TESTING_CHECKLIST.md`: streamlined regression list that covers timers, settings, and notification interactions.

## Legacy & Deep Dive Materials

- `archive/TESTING_VERIFICATION.md`: exhaustive 100+ step matrix retained for full validation cycles.
- `archive/REFACTORING_SUMMARY.md`, `archive/REFACTORING_COMPLETION_SUMMARY.md`: historical notes on the large refactor and benchmarks.
- `archive/*.md`: targeted fix logs, debug notes, and historical RCA documents. Consult these only when researching past defects.

> Tip: if you need a document that is not listed under **Active References**, check the archive first before creating a new file.
